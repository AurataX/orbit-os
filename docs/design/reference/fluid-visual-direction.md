# Visual anchor: architectural atmosphere, precise controls

The included `reference.png` is the latest image supplied by the user. It is an inspiration reference, not an original asset generated for this package. The design direction below reflects the qualities the user selected; it does not require copying the screen or its content.

## Qualities to retain

- An architectural environment with depth, a distant landscape and directional light.
- Smoked translucent controls whose edges pick up restrained highlights.
- A calm, readable foreground rather than a dense wall of widgets.
- A floating dock, small top utilities and an understandable option/workspace picker.
- A limited metallic treatment for active or primary controls.
- Plenty of visible atmosphere around a purposeful workspace.

## Make the next product original

Begin with its real task. A modelling tool should centre the model; a writing tool the document; an audio tool the timeline. The reference's creator metrics, greeting and action cards are sample content, not the required architecture. Preserve all needed features through visible or contextual access.

Use more atmosphere on an entry view and stronger surfaces during concentrated work. Keep control locations stable. Compare dock placements with actual content and device sizes before selecting one. Custom icons should form one recognisable family and animate only when state or action benefits from it.

## Image-generation prompt

Create an original high-fidelity desktop workspace concept for [PRODUCT] serving [AUDIENCE] doing [PRIMARY TASK]. Use the supplied reference only for atmospheric depth, smoked glass, material restraint and a floating navigation layer. Do not reproduce its layout, branding, greeting, metrics or content.

Compose a photoreal architectural environment with restrained metallic structure, soft indirect lighting, a quiet distant landscape and a protected low-detail region behind the working area. The environment should create a believable sense of depth. Place a crisp, readable [MAIN WORKING SURFACE] in the foreground. Show realistic content for [EXAMPLE OBJECT], one clear next action and only the controls needed for the current task.

Use [CHOSEN DOCK POSITION] for labelled primary navigation, a compact workspace picker and utility controls in the top-right region, and contextual tools close to their affected content. Keep the composition asymmetric only where the task supports it. Use smoked glass selectively, subtle metal on active controls, consistent custom line icons, clear typography and generous useful space. Keep content readable over the brightest part of the environment.

Render a straight-on application screenshot with no browser frame, device mockup or operating-system taskbar. Avoid decorative KPI grids, neon edges, oversized bloom and repeating floating cards. Include a second focused-work state if requested. This is a static visual proposal; do not depict or claim measured animation performance.
